# 07 老师可能追问：有证据的简答

1. **到底优化什么？** Python 矩阵分支在给定组内 UE/服务 mask/rank 下优化复 `V`；PF 支最大化 `Σ_scheduled log(1+R_u/f)` 的估计代理，非 PF 支为估计总谱效。关联/调度由 `scenario.py` 规则预定。旧 `cf_search` 搜索 9 维控制参数；其原生条件后端只允许连接数与 rank 进入新求解。[`solver.py:154-189,291-441`; `cf_chasi_native_resources.m`]
2. **谁发什么，为什么多站可相干？** 同 UE 的抽象单位协方差流 `s_i` 被服务站的 `V_li` 同时映射，UE 处先复数相加 `G_ki=Σ_lH_klV_li`。它假定跨站同步与已知相位，未显式仿真波形/同步误差。[`solver._effective`]
3. **V 是 MR、RZF 还是功控？** SVD 只是初始方向；矩阵支后续 CG/ADMM 自由更新允许的复元素和功率。`fixed_direction_power` 才是固定 SVD 方向加非负标量 μ。官方 MathWorks 页面写 ZF `W_k`，并非本项目 V。[`solver._initial,_solve_v_admm,_solve_fixed_direction`; 官方页面]
4. **2Tx/4Rx 与 rank 2 什么关系？** 2 是 UE 上行 SRS Tx 端口，映射到 4 个 DL Rx 行中的两行；4Rx 是下行接收维度上限，rank 是单UE下行空间流数，默认2但可配置1至4。[`config.py:12,30,62-72`; `scenario.py:239-252`]
5. **为什么有 U、W 又有 V？** `U` 是 UE 接收矩阵 4×d；`E` 是 d×d MSE；`W=E^{-1}` 是 MSE 权重；`V` 是站侧 64×d 预编码。旧 MATLAB `W` 则是预编码，官方示例 `W_k` 是 ZF，符号同名不代表同物理量。[`solver._state`; `cf_evaluate_candidate.m`; 官方页面]
6. **误差鲁棒性是哪一种？** `Σ_lP_lC_kl` 是高斯后验的期望误差协方差处理；`ellipsoid.py` 是限制子问题验证，非主求解最坏情况鲁棒目标；`uniform_error.py` 是模型消融；旧 SRS 的合成扰动又是另一模型。不能合称椭球鲁棒最优。[`solver._state`; `run.py` 分支]
7. **ADMM 是分布式部署吗？** 否。它在一个进程中集中分裂 `X=Z`，投影跨组汇总每TRP功率；`local.py` 只估计接口交换量。局部残差达标或上限不证明全局最优。[`solver.py:1-3,227-275`; `local.py`]
8. **最终用哪种信道报告？** 优化一般看 `H_est`，ideal 对照用 `H_true`；最终所有分支同一 `evaluate` 把 V 放到 held-out `H_true` 上算 logdet 静态谱效和业务代理。[`solver.solve:317-322`; `evaluate.py:103-139`]
9. **边缘5%能否称华为验收通过？** 不能。默认340 TTI 无完整1秒 UE 秒样本；ACK RLC SDU 计数、共同基线、缺失样本和分位数口径未定，`acceptance_contract` 明置 `formal_edge_mbps` 与 80% 判定为 null。[`protocol_contract.py:134-146`]
10. **MATLAB 迁移到哪一步？** 独立 `chasi_matrix_wmmse.m` 已有矩阵 PF 等分支，小夹具和旧 MATLAB 条件候选评价器可调用；但 `run_chasi_formal.m` 的21TRP入口仍调 Python，完整场景/业务/动态回放未由原生 MATLAB 替代。[`cf_evaluate_chasi_native_candidate.m`; `cf_run_chasi_formal.m`; `native_pf_20261014/README.md`]
11. **为何不能说项目来自 MathWorks？** 官方示例是20 AP/4 UE 的 CDL+PHY/ZF/BLER网络仿真；本仓库没有可核实复制/改写其 helper 的证据，核心目标和算法均异。只能做概念对照。[05,06]
12. **旧 `basic` 是不是无协作基线？** 不是，旧 basic 用 top-K 多站服务与 MRT 风格波束。Python 的 `no_cooperation` 则 home-only 本地 SVD、按政策用满本地预算。两者不能同名比较。[`cf_evaluate_candidate.m:7-15`; `solver.py:444-476`]
