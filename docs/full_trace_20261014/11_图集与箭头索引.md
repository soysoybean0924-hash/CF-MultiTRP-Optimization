## CF 图 01/05/07/08：图中公式框的完整写法

所有矩阵维度按一个组 `g` 记。`L=21`、`N_t=64`、`N_r=4`、`K_g=|Resource.users|`、`d=rank≤4`；`H_{k l}∈C^{4×64}`、`V_{l i}∈C^{64×d}`、`G_{k i}∈C^{4×d}`、`U_k∈C^{4×d}`、`E_k,W_k∈C^{d×d}`。`k` 是**接收** UE，`i` 是数据所有者，`l` 是 TRP，实际数组均另有 `g` 轴（资源列表）；`s_i,x_l,y_k` 未实例化。维度检查：`H_kl V_li` 为 `4×d`，`U_k^H y_k` 为 `d×1`。

| 框号 | 式子、条件与数据去向 | 代码 |
|---|---|---|
| F01 | `x_l=Σ_{i∈K_g}V_li s_i`，`E[s_i s_j^H]=δ_ij I_d`；等效发射式，项目只存 V 和求范数。`serve[l,i]=0 ⇒ V_li=0`。 | `solver.py:47-49,75-77`（模型等效） |
| F02–F03 | `y_k=Σ_l H_kl x_l+n_k=Σ_i G_ki s_i+n_k`，`G_ki=Σ_l H_kl V_li`。同一 i 的多 TRP 先**复数相加**；有用 `G_kk`，其他 i 是干扰。非服务 `l` 对 k 仍可能以 `H_kl V_li` 干扰。 | `solver.py:75-90`；[09](09_物理系统与信号方向.md) 给出保存场景 UE0/23 展开（模型等效） |
| F04 | `ŝ_k=U_k^H y_k`；U 是 4×d 接收矩阵，代码仅用协方差更新，未生成 ŝ。 | `solver.py:94-111`（模型等效） |
| F05–F07 | `cfg→Resource.users,serve,H_true→H_est,C→V_0`；`V_0` 取 H_est 的右奇异子空间再跨组投影。UE 2Tx 只映射 SRS 的两行，不限定下行 `d≤2`；其余 4Rx 行来自模型 CSI-RS。 | `config.py:7-98`,`scenario.py:87-128,155-284`,`solver.py:278-289` |
| F08 | `R_yy,k=I_4+Σ_iG_kiG_ki^H+Σ_lP_lg C_kl`，`P_lg=Σ_i‖V_li‖_F²`。`C_kl` 为 4×4 后验协方差；`I_4` 是噪声归一。 | `solver.py:94-105` |

| F12 | `min Σ_g a_g(⟨V_g,Q_gV_g⟩−2Re⟨B_g,V_g⟩)`，s.t. `Σ_ga_gΣ_i‖V_gli‖²≤20 W` 每 l，且非服务置零。CG 近似解 `(a_gQ_g+ρI/2)X_g=a_gB_g+ρ(Z_g−Y_g)/2`；`Z=Π_C(X+Y)`，`Y←Y+X−Z`；返回可行 Z 后试 `V_old+α(Z−V_old)`。投影与停止的数值细节见 [03 C27–C31](03_公式索引.md)。 | `solver.py:52-73,200-276,343-441` |

## 官方图 02–04：每条箭头

`m` 是 AP，`k` 是 UE，`M_k` 是 UE k 的**最近两个**服务 AP；官方当前页配置 20 AP/4 UE。AP 有 4Tx/4Rx，UE 1Tx/1Rx，所以单 UE 两服务 AP 的联合上行 CSI 可按可见公式解释为 8×1；helper 内部矩阵实际批次维度不可见。`O` 公式的页面位置和可见性见[独立字典](10_MathWorks符号与公式.md)。图 02a 的 AP A–F/UE k,j 是规则示意，没有伪造一次实际随机抽样的 AP ID。非服务无线干扰的逐链功率式在当前官方页不可见，故不在主拓扑画成已核实箭头。
