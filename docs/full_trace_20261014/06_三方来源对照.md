**2023 与当前 V 的边界。** 原 `WMMSE_ADMM_Func.py` 优化 `mu_MR_WMMSE[l,k]=√p`：固定 MR 方向、单流实数功率，统计 `a_MR/B_MR` 输入；小写 `v[k]` 为标量接收器、`w[k]` MSE 权重、`q/g` ADMM 副本/对偶。当前 `solver.py` 以 `H[K,L,4,64]`、用户中心 mask、rank d、复 `V[L,K,64,d]` 构造 `U/E/W/Q`，跨 17 组投影；参考结构是方法思想，矩阵二次项/误差项/CG/回溯为项目重推。原论文已有导频复用/统计非理想 CSI，不能声称“首次处理异质误差”。`source_manifest_20261012.json` 保留参考本机位置和旧 SHA，但其 Python solver SHA 与本轮工作树不应直接等同。项目源码/提交未见 MathWorks helper 的拷贝或直接改写痕迹；**MathWorks→本项目的直接源码继承关系来源未证实**。
