# 12 旧 W、新 V、官方 W 与论文 μ/v：逐接口核查

## 结论先定位

旧 MATLAB `W(:,s,r,u,g)` 与 CHASI Python `V[l,k,:,d]` 都是**下行发射端的复线性映射系数**，但它们的用户/资源轴、约束、初始化、更新和评价定义不同。默认链之间**没有** `oldW→newV` 赋值或导入。`cf_run_chasi_formal.m:52-65` 只把标量配置送入 Python，读回 Python 保存的 `V/U/W`；它不消费旧 `result.W`。条件原生路径 `cf_evaluate_candidate.m:4-6` 在函数开头**直接返回** `cf_evaluate_chasi_native_candidate`，并以 `cf_chasi_native_resources` 从旧场景 `H_est/H_true` 重组资源，调用 `chasi_matrix_wmmse`，也没有把旧波束 `W` 当初始 V。故“旧 W 自然改名为新 V”是错误的数据流图。

## 单位、索引、重排和消费风险

1. **旧 MATLAB 轴** `H[Nr,M,R,U,G]`,`W[M,S,R,U,G]`；旧 `Hstack=[H_r]` 沿**发射天线列**拼，`Q` 用左奇异向量。`computeMetrics` 把所有 TRP 的 `W` 堆成 `[M×R,S×U]`，以 `col=(s−1)U+u` 索引；`Hquery^H Wmasked` 才得每个查询流对每个数据流的复振幅。`W` 功率为归一化量，`maxDUPower=1` 默认。
2. **新 Python 轴** `h[K_g,L,Nr,Nt]`,`V[L,K_g,Nt,d]`。`np.einsum('klrn,linq->kirq')` 中 `k` 是接收 UE、`i` 数据所有者、`l` TRP、`r` 接收端口、`n` 发射端口、`q` 流；跨 `l,n` 求和。`K_g` 每组可变，不等全局 N。`_quadratic_parts` 用 `h.conj()`，等价 `H^H`，`_state` 用 `u.conj().T`，不是普通转置。`np.savez`/`savemat` 保留形状；MATLAB 导入本身不会替你交换索引。
3. **适配器转换** `cf_chasi_native_resources.m:17-115` 要求显式 `scheduleMask[U,G]`、总和 273 的 `rbCounts`、`budget,pfFloor,covarianceRule`；将 `scenario.H_est(:,:,l,u,g)/sqrt(noisePower)` reshape 到 `H[k,l,Nr,Nt]`，协方差按 `noisePower` 归一；从 `scenario.channelGain` 选服务 TRP。旧标量 SRS 误差仅可用 `e·estimatedGain·I` 代理，或调用者外供完整接收协方差；这与 Python 每链 `[4,4]` 后验不是天然相等。`numConnections,maxRank` 之外七个候选维度变化会报错。**定义不同但有显式转换**，转换假设须单独验证。
4. **物理功率** 新 `P_l=Σ_g(tx_rb_count_g/273)Σ_i||V_{g,l,i}||_F²` W；旧 `p_{r,u,g}=Σ_s||W_{:,s,r,u,g}||²`，再逐 `r,g` 限制。两者不同规模/单位，不可直接相等或把旧 `p` 值乘到新 V 上。`fixed_direction_power` 则 `V=μD`，已包含 μ；评价器不再乘额外功率。
5. **真信道与重复使用** 旧 `cf_apply_srs_measurement_model.buildPresinr:88-106` 用 `H_true` 增益决定合成测量质量，故真值可能经误差幅度间接进入初始化；这不是直接把真 H 交给搜索。新 `scenario.generate:235-268` 也用真 H 产生 CSI 观测；`ideal` 直接优化真 H，其他分支用估计。两种“held out”都应说明生成依赖。静态真信道评价不把 `omitted_gain` 添回干扰分母，截断误差只诊断。
6. **可能问题而非既成 bug**：旧 `result.W` 与新 `V` 无桥，若有人将两者画成连续箭头属于**接口尚未接通**；原生适配器的协方差代理与 Python 后验为**模型不等价**；Python 一组一个 V 且默认每 TRP 随机选择整组 RB，TRP 间 RB 不必共享，干扰按同组全重叠是**模型近似**。功率重复乘、`reshape` 错位尚无本轮运行证据证明已发生；仅凭符号不应定性为现存 bug。建议后续用同输入夹具核对维度/共轭/功率，不在本轮改算法。

## WMMSE＋ADMM 数学与实际停止

目标分支必须先定：`matrix_statistical` 的外轮快照为 `Σ_g a_gΣ_k[-log₂det E_gk]`；PF 支为 `Σ_{scheduled u}log(1+R_u/f)`（`R_u=Σ_ga_gr̂_gk`）；`ideal` 用 `H_true`。统计误差的 `-logdet E` 是**模型代理**，不等最后真信道 logdet。令 `E_s` 为 d×d 正定 MMSE 矩阵；在高斯独立单位协方差数据、线性接收、恰当干扰噪声协方差及最优 `U` 条件下，`max_U,W≻0 logdet W−tr(WE)+d` 给与 `−logdet E` 等价的局部变换；代码的 `W=E^{-1}` 与 `U=R_yy^{-1}G` 实现这一块更新，PF 再加外轮导数 `ω`。它不是对非凸联合问题的全局最优证明。`solver.py:94-124,136-190`。

固定 `U,W,ω`，`M_k=U_k(ω_kW_k)U_k^H`、`B_lk=H_kl^HU_k(ω_kW_k)`、`D_l=Σ_ktr(M_kC_kl)`，二次目标 `f(V)=Σ_ga_g(⟨V_g,Q_gV_g⟩−2Re⟨B_g,V_g⟩)`，`Q_gV` 如[03 C25](03_公式索引.md)。服务外 `V=0`，rank d 固定，预算 `Σ_ga_g||V_{g,l}||²≤20W`。`X=Z` 分裂后，CG 近似解 `(a_gQ_g+ρI/2)X_g=a_gB_g+ρ(Z_g−Y_g)/2`，`Z=Π_C(X+Y)`，`Y←Y+X−Z`。`Y` 是缩放对偶，`ρY` 未单独存储。投影按 TRP 在所有组共享乘子 λ，`Z_{g,l}=T_{g,l}/(1+λ_la_g)`，二分 λ 到跨组功率可行。`solver.py:52-73,192-276`。

ADMM 内层同时要求 `||X−Z||≤eps_primal`,`ρ||Z−Z_old||≤eps_dual` 及 CG 相对残差门槛，最多 `admm_iterations`；`ρ` 每10轮可调整并重缩放 `Y`。返回的是**可行副本 Z**，不是 CG 的 X。WMMSE 外轮 `solve:343-441` 最多 `outer_iterations` 次，Z 经最多12次半步回溯检查估计目标不降；局部收敛还需目标相对变化、V 相对变化、**最近一次 ADMM 达标**。到上限、ADMM 不精确、拒绝步或 objective decrease 分别留原因。最终 `evaluate.py` 固定 V、用真 H 算静态 SE/体验代理；这不是最优性或华为验收证明。
