**实测细节：**[JSON摘要](CHASI_TOPOLOGY_VALIDATION_20261019.json)来自 `tests/chasi_validate_topology_scene.m` 直接调用 `chasi_generate_scene`，只生成场景，未运行求解器。210 UE的环扇面积坐标均值0.54529、KS=0.07851（5%参考界0.09385）；420 UE分别0.51733、0.04934（参考界0.06636）。一次样本的KS不拒绝不能证明均匀，主要依据是新的逆CDF公式及显式输入单元测试。图：[PNG](chasi_native_atlas/13_cell_layout_seed20261011.png)、[PDF](chasi_native_atlas/13_cell_layout_seed20261011.pdf)；可编辑绘图源 `matlab/chasi/chasi_plot_cell_layout.m` 由 MATLAB 输出矢量 PDF，PNG 预览从该 PDF 渲染（当前 Windows MATLAB 批处理直接导出 PNG 偶发全黑）。图中虚线是**模型边界**，并非验收原图轮廓；图未画服务或干扰边。

旧默认 `d=25+125 sqrt(U)` 对25～150m环扇区不满足面积均匀。本次将正式默认改成正确公式，保留 `ueSpatialSampling='legacy_sqrt_radius'` 用于历史场景重现，不修改旧结果。旧保存场景 `results/chasi_matlab/formal210_20261018_double_precision/scene_manifest.json` 的面积坐标KS=0.14839，大于0.09385参考界。旧场景同显式输入的求解器、CSI和ADMM程序对拍仍有旧模型下的数值验证价值；旧场景的真实信道速率、边缘体验、功率性能不能作为**新场景**结论，需另跑。没有证据预报此次修改提高性能。旧Python参考仍按旧公式，历史几何对拍导出已明确选择 legacy 模式，不能把模型变化误判为迁移误差。

**边界备选：**当前环扇区便于严格面积采样，但站间留有空隙；六边形站点分区再切三个扇区可覆盖中心区域，但外围截断和最小距离须另定；其他多边形需原始边界数据。验收原图不足以指定其中一种。代码当前无wrap-around。
